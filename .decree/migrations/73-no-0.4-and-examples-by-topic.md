# 73: Remove everything 0.4, and split `mock/` into examples by topic

## Overview

Two cleanups the user decided on:

1. **Everything 0.4 goes.** This repository is on 0.5, and the upgrade path has done its job. What goes:
   - the upgrade script and its tests;
   - the 0.4 fixtures;
   - the tests that compare the built-in machines with 0.4.2's routines;
   - the error for a leftover `.decree/config.yml`;
   - the `routine:` alias for `machine:`. No pending migration uses it; processed migrations are never read again.

   `docs/decisions.md` and git history keep the story.
2. **`mock/` becomes examples, split by topic.** `mock/` was the worked example written before 0.5 existed. Its content is still useful (it is the project the reference docs quote, and the replay tests run its recorded runs), but it belongs in `examples/`, and one big project is harder to browse than a few focused ones.
